# 체형별 스타일 가이드

## 체형 유형

### 사과형 (Apple)
- 특징: 상체가 하체보다 큰 편, 허리 라인이 덜 뚜렷
- 장점: 다리가 예쁜 경우 많음, 얼굴이 작아 보임

추천 스타일:
- V넥, 딥 유넥으로 상체 라인 정리
- A라인 원피스로 허리 아래 커버
- 다리를 드러내는 미니/미디 기장
- 상의는 편안하게, 하의는 슬림하게

피해야 할 스타일:
- 타이트한 상의
- 하이넥, 라운드넥
- 허리를 강조하는 벨트
- 볼륨있는 상의

### 배형 (Pear)
- 특징: 하체가 상체보다 큰 편, 엉덩이/허벅지 볼륨
- 장점: 상체가 날씬하고 허리가 잘록

추천 스타일:
- 보트넥, 오프숄더로 어깨 라인 강조
- A라인 스커트로 힙 커버
- 밝은 색 상의 + 어두운 색 하의
- 패드 있는 재킷으로 어깨 보정

피해야 할 스타일:
- 스키니진 (적당한 스트레이트 추천)
- 밝은 색 하의
- 힙에 디테일 있는 디자인
- 타이트한 스커트

### 모래시계형 (Hourglass)
- 특징: 가슴과 엉덩이 볼륨이 있고 허리가 잘록
- 장점: 균형 잡힌 몸매, 여성스러운 라인

추천 스타일:
- 허리를 강조하는 벨트
- 바디컨 드레스
- 랩 원피스, 랩 블라우스
- X라인 실루엣

피해야 할 스타일:
- 박시한 실루엣 (체형 장점을 숨김)
- 일자 원피스
- 너무 오버사이즈한 옷

### 역삼각형 (Inverted Triangle)
- 특징: 어깨가 넓고 상체가 큰 편
- 장점: 시원시원한 인상, 옷이 잘 받음

추천 스타일:
- V넥으로 상체 라인 정리
- 볼륨있는 하의 (와이드 팬츠, 플레어 스커트)
- 어두운 색 상의 + 밝은 색 하의
- 심플한 상의 디자인

피해야 할 스타일:
- 패드 있는 어깨
- 보트넥, 오프숄더
- 가로 스트라이프 상의
- 어깨에 디테일 있는 디자인

### 직사각형 (Rectangle)
- 특징: 전체적으로 일자 체형, 허리 굴곡이 덜함
- 장점: 다양한 스타일 소화 가능, 옷이 깔끔하게 떨어짐

추천 스타일:
- 허리 벨트로 굴곡 만들기
- 페플럼 탑/블라우스
- 레이어드 스타일링
- A라인, X라인 실루엣

피해야 할 스타일:
- 일자로 떨어지는 원피스
- 밋밋한 실루엣
- 너무 타이트한 옷 (굴곡 없음이 강조됨)

## 키에 따른 스타일링

### 키가 작은 편
- 하이웨스트로 다리 길어 보이게
- 세로 라인 강조
- 같은 톤으로 통일감
- 크롭 기장 주의 (비율 확인)

### 키가 큰 편
- 레이어드 자유롭게
- 롱 기장 아이템 잘 소화
- 가로 라인도 OK
- 오버사이즈 핏 잘 어울림
