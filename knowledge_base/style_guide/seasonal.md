# 계절별 스타일 가이드 (2026)

기준: 2026년 실무 스타일링 흐름 반영.  
원칙: 퍼스널컬러를 중심축으로 두고, 트렌드는 1~2개 포인트로만 적용.

## 공통 스타일 공식

- 기본 구성: 베이스 컬러 60 + 보조 30 + 포인트 10
- 실루엣: 상체/하체 중 한 쪽만 볼륨 강조
- 소재: 한 착장에 2~3개 텍스처 조합(예: 코튼 + 니트 + 레더)
- 컬러 포인트: 신발/가방/아우터 중 1개에 집중

## 봄 (Spring)

### 무드
- 가벼운 레이어드, 생기 있는 컬러 포인트
- 트렌치/가디건 중심의 간절기 조합

### 추천 아이템
- 라이트 트렌치, 얇은 니트, 셔츠, 스트레이트 데님
- 로퍼, 발레 플랫, 미들힐

### 퍼스널컬러 적용
- Spring Warm: 코랄, 피치, 아이보리, 웜 베이지
- Summer Cool: 라벤더, 소프트 블루, 로즈핑크
- Autumn Warm: 카멜, 올리브, 크림
- Winter Cool: 화이트, 네이비, 차콜 + 선명 포인트

## 여름 (Summer)

### 무드
- 통기성/흡습성 중심, 간결한 실루엣
- 선명한 컬러는 한 아이템으로 제한

### 추천 아이템
- 린넨 셔츠, 슬리브리스 니트, 와이드 팬츠, 셔츠드레스
- 샌들, 슬링백, 가벼운 스니커즈

### 퍼스널컬러 적용
- Spring Warm: 피치, 라이트 코랄, 바닐라 톤
- Summer Cool: 스카이블루, 라일락, 쿨그레이
- Autumn Warm: 올리브, 샌드, 브릭 포인트
- Winter Cool: 퓨어 화이트, 코발트, 블랙 포인트

## 가을 (Autumn)

### 무드
- 텍스처 중심(니트/스웨이드/울)
- 톤온톤 레이어드와 깊은 컬러 조합

### 추천 아이템
- 미디 코트, 니트 폴로, 테일러드 재킷, 미디 스커트
- 로퍼, 앵클부츠

### 퍼스널컬러 적용
- Spring Warm: 카멜 + 아이보리 + 코랄 포인트
- Summer Cool: 그레이 + 라벤더 + 네이비
- Autumn Warm: 테라코타, 머스타드, 올리브, 버건디
- Winter Cool: 블랙, 차콜, 와인, 로열블루

## 겨울 (Winter)

### 무드
- 구조적인 아우터 + 간결한 이너
- 어두운 베이스에 선명한 포인트 컬러

### 추천 아이템
- 롱코트, 하이게이지 터틀넥, 울 슬랙스, 기모 데님
- 부츠, 포인티드 플랫, 구조적인 백

### 퍼스널컬러 적용
- Spring Warm: 아이보리/카멜 코트 + 웜 포인트
- Summer Cool: 쿨그레이/네이비 + 소프트 핑크 포인트
- Autumn Warm: 브라운/카키/버건디 중심
- Winter Cool: 블랙&화이트, 에메랄드, 마젠타 포인트

## 2026 추천 운영 규칙

- 트렌드 강도 조절: 데일리룩은 20~30%만 반영
- 출근룩: 뉴트럴 베이스 + 컬러 1포인트
- 데이트룩: 텍스처(새틴/니트) 대비로 분위기 강화
- 주말룩: 데님/셔츠 중심으로 편안함 우선
