# 여름 쿨톤 (Summer Cool) 스타일 가이드

## 특징
여름 쿨톤은 부드럽고 차가운 색상이 잘 어울리는 타입입니다. 피부톤이 핑크빛 또는 푸른 기가 있으며, 우아하고 세련된 이미지를 가지고 있습니다.

## 피부 특징
- 핑크빛 또는 푸른 기가 도는 피부
- 쿨한 언더톤
- 피부가 얇고 투명한 느낌
- 햇빛에 쉽게 붉어지거나 타지 않음

## 어울리는 색상

### 메인 컬러
- 라벤더 (Lavender): 여름 쿨톤의 시그니처
- 로즈 핑크 (Rose Pink): 우아한 핑크
- 스카이 블루 (Sky Blue): 시원하고 청량한 느낌
- 민트 (Mint): 상쾌한 포인트
- 소프트 화이트 (Soft White): 순백보다 부드러운 톤

### 서브 컬러
- 그레이 (Gray): 다양한 톤 활용 가능
- 네이비 (Navy): 블랙 대신 사용
- 라일락 (Lilac): 보라 계열
- 소프트 핑크 (Soft Pink): 파스텔 톤
- 블루 그레이 (Blue Gray): 세련된 느낌

### 피해야 할 색상
- 오렌지 (Orange): 얼굴이 누렇게 보임
- 머스타드 (Mustard): 칙칙해 보임
- 카키 (Khaki): 피부 톤 다운
- 강한 노랑 (Strong Yellow): 부조화
- 테라코타 (Terracotta): 너무 따뜻함

## 메이크업 추천

### 베이스
- 핑크 언더톤의 파운데이션
- 로즈 또는 핑크 블러셔
- 실버 펄 하이라이터

### 립 컬러
- 로즈 핑크 립스틱
- 베리 톤 틴트
- 쿨 레드 (오렌지 기 없는)
- 말린 장미색 (Dusty Rose)

### 아이 메이크업
- 라벤더, 핑크 아이섀도우
- 그레이 또는 소프트 블랙 아이라이너
- 타우프 (Taupe) 계열 섀도우
- 실버 펄 포인트

## 패션 스타일링 팁

### 캐주얼룩
- 라벤더 니트 + 화이트 팬츠
- 스카이 블루 셔츠 + 그레이 청바지
- 민트 티셔츠 + 네이비 쇼츠

### 오피스룩
- 그레이 수트 + 라벤더 블라우스
- 네이비 원피스 + 실버 액세서리
- 소프트 화이트 재킷 + 그레이 팬츠

### 데이트룩
- 로즈 핑크 원피스 + 실버 주얼리
- 라벤더 스커트 + 화이트 블라우스
- 민트 블라우스 + 화이트 팬츠

## 액세서리 추천
- 실버 주얼리 (골드보다 실버)
- 진주 액세서리
- 로즈 쿼츠 보석
- 그레이 또는 네이비 가방
- 은은한 펄 느낌의 소품

## 헤어 컬러 추천
- 애쉬 브라운
- 애쉬 그레이
- 쿨 브라운
- 라벤더 브라운
- 블루 블랙
