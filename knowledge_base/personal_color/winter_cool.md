# 겨울 쿨톤 (Winter Cool) 스타일 가이드

## 특징
겨울 쿨톤은 선명하고 강렬한 색상이 잘 어울리는 타입입니다. 피부와 머리카락, 눈동자의 대비가 뚜렷하며, 시크하고 도시적인 이미지를 가지고 있습니다.

## 피부 특징
- 밝은 아이보리 또는 올리브 피부
- 쿨한 언더톤 (핑크 또는 푸른 기)
- 피부와 머리카락 대비가 뚜렷
- 햇빛에 잘 타지 않거나 금방 돌아옴

## 어울리는 색상

### 메인 컬러
- 퓨어 화이트 (Pure White): 겨울 쿨톤만의 특권
- 블랙 (Black): 시그니처 컬러
- 로얄 블루 (Royal Blue): 선명한 파랑
- 와인 (Wine): 깊은 보라빛 레드
- 에메랄드 (Emerald): 선명한 그린

### 서브 컬러
- 실버 (Silver): 액세서리 필수
- 퓨시아 (Fuchsia): 강렬한 핑크
- 아이시 핑크 (Icy Pink): 차가운 파스텔
- 차콜 (Charcoal): 블랙 대안
- 플럼 (Plum): 깊은 보라

### 피해야 할 색상
- 베이지 (Beige): 칙칙해 보임
- 오렌지 (Orange): 전혀 어울리지 않음
- 연한 파스텔 (Soft Pastels): 힘이 빠져 보임
- 브라운 (Brown): 웜톤 색상
- 카키 (Khaki): 피부 톤 다운

## 메이크업 추천

### 베이스
- 핑크 또는 뉴트럴 언더톤 파운데이션
- 와인 또는 로즈 블러셔
- 실버 하이라이터

### 립 컬러
- 와인 립스틱
- 트루 레드 (True Red): 쿨톤 레드
- 핫 핑크 (Hot Pink)
- 베리 (Berry)
- 플럼 (Plum)

### 아이 메이크업
- 실버, 그레이 아이섀도우
- 블랙 아이라이너 (강조)
- 스모키 메이크업 추천
- 네이비, 플럼 컬러 섀도우

## 패션 스타일링 팁

### 캐주얼룩
- 블랙 터틀넥 + 화이트 팬츠
- 로얄 블루 니트 + 블랙 진
- 와인 티셔츠 + 차콜 팬츠

### 오피스룩
- 블랙 수트 + 화이트 셔츠
- 네이비 원피스 + 실버 액세서리
- 차콜 블레이저 + 블랙 팬츠

### 데이트룩
- 와인 원피스 + 실버 주얼리
- 에메랄드 블라우스 + 블랙 스커트
- 핫 핑크 니트 + 화이트 팬츠

## 액세서리 추천
- 실버 주얼리 (필수)
- 다이아몬드, 크리스탈
- 블랙 레더 제품
- 화이트 또는 블랙 가방
- 에나멜 소재 추천

## 헤어 컬러 추천
- 블루 블랙
- 제트 블랙
- 다크 애쉬 브라운
- 버건디 포인트
- 플래티넘 (과감한 선택)

## 모노톤 스타일링
겨울 쿨톤은 모노톤 스타일링이 특히 잘 어울립니다:
- 올 블랙 룩
- 블랙 & 화이트 조합
- 그레이스케일 그라데이션
- 포인트 컬러 하나만 추가
