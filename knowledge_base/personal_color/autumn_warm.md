# 가을 웜톤 (Autumn Warm) 스타일 가이드

## 특징
가을 웜톤은 깊고 따뜻한 색상이 잘 어울리는 타입입니다. 피부톤이 노란 기나 올리브 빛이 있으며, 성숙하고 고급스러운 이미지를 가지고 있습니다.

## 피부 특징
- 노란 기 또는 올리브 톤 피부
- 깊은 웜 언더톤
- 피부가 두껍고 건강해 보임
- 햇빛에 쉽게 타고 오래 유지됨

## 어울리는 색상

### 메인 컬러
- 테라코타 (Terracotta): 가을 웜톤의 시그니처
- 머스타드 (Mustard): 노란 계열의 대표
- 올리브 (Olive): 그린 계열 추천
- 버건디 (Burgundy): 깊은 레드
- 카키 (Khaki): 내추럴한 느낌

### 서브 컬러
- 다크 브라운 (Dark Brown): 기본 컬러
- 번트 오렌지 (Burnt Orange): 가을 느낌
- 골드 (Gold): 액세서리 필수
- 모스 그린 (Moss Green): 자연스러운 그린
- 카멜 (Camel): 봄보다 깊은 톤

### 피해야 할 색상
- 파스텔톤 (Pastels): 힘이 빠져 보임
- 네온 컬러 (Neon): 부조화
- 쿨 핑크 (Cool Pink): 어울리지 않음
- 밝은 파랑 (Bright Blue): 차가움
- 퓨어 화이트 (Pure White): 창백해 보임

## 메이크업 추천

### 베이스
- 올리브 또는 노란 언더톤 파운데이션
- 테라코타 또는 브릭 블러셔
- 골드 브론즈 하이라이터

### 립 컬러
- 테라코타 립스틱
- 브릭 레드 (Brick Red)
- 브라운 누드
- 버건디 립
- 오렌지 브라운

### 아이 메이크업
- 브론즈, 골드 아이섀도우
- 브라운 또는 카키 아이라이너
- 코퍼 (Copper) 톤 섀도우
- 테라코타 컬러 포인트

## 패션 스타일링 팁

### 캐주얼룩
- 머스타드 니트 + 다크 브라운 팬츠
- 카키 재킷 + 버건디 티셔츠
- 테라코타 스웨터 + 올리브 카고 팬츠

### 오피스룩
- 브라운 수트 + 아이보리 블라우스
- 카멜 코트 + 버건디 스카프
- 올리브 블레이저 + 크림 팬츠

### 데이트룩
- 버건디 원피스 + 골드 주얼리
- 테라코타 스커트 + 크림 블라우스
- 머스타드 니트 + 브라운 레더 스커트

## 액세서리 추천
- 골드 주얼리 (앤틱 골드 추천)
- 호박 (Amber) 보석
- 브라운 레더 제품
- 카멜 또는 탄 컬러 가방
- 터콰이즈 포인트 (의외로 잘 어울림)

## 헤어 컬러 추천
- 다크 브라운
- 초콜릿 브라운
- 카퍼 (Copper)
- 오번 (Auburn)
- 에스프레소
