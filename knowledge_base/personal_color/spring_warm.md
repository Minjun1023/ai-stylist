# 봄 웜톤 (Spring Warm) 스타일 가이드

## 특징
봄 웜톤은 밝고 따뜻한 색상이 잘 어울리는 타입입니다. 피부톤이 밝고 노란 기가 있으며, 전체적으로 화사하고 생기 있는 이미지를 가지고 있습니다.

## 피부 특징
- 밝은 아이보리 또는 피치 빛 피부
- 노란 언더톤
- 주근깨가 있는 경우가 많음
- 햇빛에 약간 붉어졌다가 금방 회복됨

## 어울리는 색상

### 메인 컬러
- 코랄 (Coral): 봄 웜톤의 시그니처 컬러
- 피치 (Peach): 부드럽고 화사한 느낌
- 살몬 핑크 (Salmon Pink): 따뜻한 핑크
- 아이보리 (Ivory): 차가운 화이트 대신
- 밝은 오렌지 (Light Orange): 생기 있는 포인트

### 서브 컬러
- 카멜 (Camel): 가을보다 밝은 톤
- 연두 (Yellow Green): 싱그러운 느낌
- 터콰이즈 (Turquoise): 시원한 포인트
- 골드 (Gold): 액세서리 추천
- 웜 베이지 (Warm Beige): 기본 컬러

### 피해야 할 색상
- 순수 블랙 (Pure Black): 너무 강해 보임
- 차가운 회색 (Cool Gray): 얼굴이 칙칙해 보임
- 버건디 (Burgundy): 너무 무거움
- 네이비 (Navy): 차가운 느낌
- 푸시아 핑크 (Fuchsia): 너무 차가움

## 메이크업 추천

### 베이스
- 노란 언더톤의 파운데이션
- 피치 또는 코랄 블러셔
- 골드 펄 하이라이터

### 립 컬러
- 코랄 립스틱
- 피치 틴트
- 오렌지 레드 (차가운 레드 피하기)
- 살몬 핑크 글로스

### 아이 메이크업
- 골드, 브론즈 아이섀도우
- 브라운 아이라이너 (블랙보다 부드러움)
- 코랄 또는 피치 톤 아이섀도우

## 패션 스타일링 팁

### 캐주얼룩
- 아이보리 니트 + 카멜 팬츠
- 코랄 블라우스 + 화이트 청바지
- 피치 원피스 + 골드 액세서리

### 오피스룩
- 베이지 수트 + 코랄 블라우스
- 카멜 코트 + 아이보리 니트
- 밝은 브라운 재킷 + 크림색 팬츠

### 데이트룩
- 피치 원피스 + 샌들
- 코랄 스커트 + 화이트 블라우스
- 살몬 핑크 니트 + 베이지 팬츠

## 액세서리 추천
- 골드 주얼리 (실버보다 골드)
- 산호색 액세서리
- 터콰이즈 포인트
- 베이지 또는 카멜 가방
- 브라운 계열 벨트와 신발

## 헤어 컬러 추천
- 밝은 브라운
- 골드 브라운
- 카라멜 하이라이트
- 구리빛 (Copper) 염색
