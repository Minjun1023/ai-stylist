# 면접 스타일 가이드 (2026)

## 원칙

- 직무 적합성 + 단정함 + 신뢰감
- 트렌드보다 핏과 청결, 정돈이 우선

## 직군별 기준

### 금융/법무/대기업 본사
- 네이비/차콜 수트 중심
- 화이트 또는 연한 블루 셔츠
- 장식 최소화

### IT/스타트업
- 스마트 캐주얼 가능
- 재킷 + 니트/셔츠 + 슬랙스 권장

### 디자인/브랜딩/콘텐츠
- 베이스는 단정하게, 포인트 1개 허용
- 과한 패턴/컬러는 지양

## 퍼스널컬러 적용(면접용)

- Spring Warm: 아이보리/웜베이지 + 코랄 립 포인트
- Summer Cool: 쿨그레이/네이비 + 로즈 포인트
- Autumn Warm: 브라운/올리브 + 테라코타 포인트
- Winter Cool: 블랙/화이트/네이비 + 와인/로열블루 포인트

## 체크리스트

- 옷 주름/오염 없음
- 신발/가방 정돈
- 헤어/손톱/향수 과하지 않음
- 장시간 착용해도 불편하지 않은지 확인
