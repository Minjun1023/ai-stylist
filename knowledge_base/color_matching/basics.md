# 색상 매칭 기본 가이드 (2026 실전형)

## 빠른 매칭 규칙

- 안전 조합: 뉴트럴(블랙/화이트/그레이/네이비/베이지) + 포인트 1색
- 고급 조합: 톤온톤(같은 계열 명도 차) + 금속 액세서리
- 트렌디 조합: 고채도 컬러는 한 아이템만 사용

## 기본 배색 방식

### 1) 보색 배색
- 대비가 강하고 시선을 끄는 조합
- 예: 블루+오렌지, 레드+그린
- 활용: 가방/신발 같은 소품으로 제한

### 2) 유사색 배색
- 안정적이고 세련된 인상
- 예: 블루-청록-그린, 핑크-코랄-오렌지

### 3) 톤온톤/톤인톤
- 같은 색상군에서 채도/명도만 조절
- 예: 네이비 + 블루그레이 + 아이스블루

## 60-30-10 실전 예시

- 60: 베이스 컬러 (코트/팬츠)
- 30: 보조 컬러 (니트/셔츠)
- 10: 포인트 컬러 (백/슈즈/주얼리)

예시:
- 네이비 60 + 화이트 30 + 토마토레드 10
- 카멜 60 + 아이보리 30 + 올리브 10

## 퍼스널컬러별 추천 조합

### Spring Warm
- 코랄 + 아이보리 + 골드
- 피치 + 웜베이지 + 카멜

### Summer Cool
- 라벤더 + 소프트화이트 + 실버
- 스카이블루 + 쿨그레이 + 로즈핑크

### Autumn Warm
- 테라코타 + 크림 + 브라운
- 올리브 + 카멜 + 골드

### Winter Cool
- 블랙 + 퓨어화이트 + 실버
- 로열블루 + 차콜 + 마젠타 포인트

## 2026 컬러 트렌드 적용법

- 토마토 레드: 블랙/네이비 베이스에 1포인트
- 시트러스 옐로: 상의 단독 또는 백 포인트
- 퍼플 계열: 니트/스커트/액세서리로 부분 적용
- 선명 그린: 아우터 또는 슈즈 중심 적용

## 피해야 할 조합

- 얼굴 근처에 비추천 컬러 과다 사용
- 고채도 3색 이상 동시 사용
- 웜/쿨 충돌 컬러를 근접 배치(예: 웜 오렌지 + 쿨 푸시아)
